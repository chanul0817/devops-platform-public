# Sample Customer Application

이 Spring Boot 애플리케이션은 고객사 서비스를 대신하는 샘플 워크로드입니다.

DevOps 컨설팅 포트폴리오에서 이 앱은 다음 검증을 위해 존재합니다.

- Docker image build
- health check
- Prometheus metrics scrape
- application log collection
- PostgreSQL connection
- smoke test

실제 고객사 적용 시에는 이 디렉터리 대신 고객사가 제공한 Docker image, jar, binary, static build를 운영 플랫폼에 연결합니다.
